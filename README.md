# Engineering portfolio template

## Editing
Everything you'll change lives in **content.js**: your name, intro, links, skills and projects.
Open it, edit the text between the quotes, save, and refresh.

**Add a project:** copy the example block in `projects`, delete the comment markers `/*` and `*/` around it, fill it in.
Put images in `assets/projects/`. The project gets its own page automatically.
**Reorder projects:** move the blocks. The first one shows first.
**Change colors or fonts:** edit the top of `styles.css`.

Preview locally by double-clicking `index.html`.

## Publish on GitHub Pages
1. Create a public repo named `your-username.github.io`.
2. Upload every file and folder here, plus your `resume.pdf`.
3. Settings → Pages → "Deploy from a branch" → `main` / root → Save.
4. Live at `https://your-username.github.io` in a minute or two.

## Tips
- Export images ~1600 px wide, under 500 KB. 4:3 works best for covers.
- Keep results short and numeric ("−120 g", "3 iterations").
- Turn on 2FA and "Keep my email addresses private" in GitHub settings.
